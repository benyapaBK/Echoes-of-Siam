# คู่มือการนำเข้าและส่งออกข้อมูล (Import & Export Guide)

## 1. การส่งออกข้อมูล (Data Export)

ระบบรองรับการส่งออกข้อมูลผ่านหน้า **Admin Console -> ส่งออกข้อมูล (Export)**:
1. **Museums CSV (UTF-8 with BOM)**: ออกแบบเฉพาะเพื่อให้โปรแกรม Microsoft Excel, Google Sheets และ Apple Numbers แสดงผลภาษาไทยได้อย่างถูกต้องโดยไม่มีปัญหาตัวอักษรเพี้ยน
2. **Museums JSON**: ไฟล์ JSON มาตรฐานสำหรับนักพัฒนา
3. **Subjects CSV / JSON**: รายการดัชนีหัวเรื่องและความถี่
4. **Knowledge Graph JSON**: โครงสร้าง Nodes และ Edges สำหรับนำเข้าสู่ระบบกราฟอื่น ๆ

---

## 2. การนำเข้าข้อมูล (Data Import)

ระบบรองรับการนำเข้าข้อมูลผ่าน **Admin Console -> นำเข้าข้อมูล (Import)**:
1. รองรับรูปแบบ JSON Array ของระเบียนพิพิธภัณฑ์
2. ระบบจะทำการตรวจสอบ:
   - ตรวจสอบฟิลด์บังคับ (`title`)
   - ตรวจสอบรายการซ้ำซ้อนตามชื่อหรือรหัส ID
   - แยกหัวเรื่องอัตโนมัติและจัดทำดัชนีหัวเรื่องใหม่
   - บันทึกการนำเข้าลงใน **Audit Logs** ทุกครั้ง
