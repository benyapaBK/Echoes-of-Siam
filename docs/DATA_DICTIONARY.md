# พจนานุกรมข้อมูล (Data Dictionary) — MUSEUM ATLAS THAILAND

ชุดข้อมูลอ้างอิงจากฐานข้อมูลพิพิธภัณฑ์ในประเทศไทย ศูนย์มานุษยวิทยาสิรินธร (องค์การมหาชน)

## ตารางระเบียนพิพิธภัณฑ์ (Museum Records)

| ชื่อฟิลด์ | ชนิดข้อมูล | คำอธิบาย | ตัวอย่างข้อมูล |
|---|---|---|---|
| `id` | String | รหัสระเบียนคงที่ประจำพิพิธภัณฑ์ (Stable ID) | `sac_1` |
| `sourceId` | String | รหัสอ้างอิงลำดับเดิมจาก ศมส. | `1` |
| `type` | String | ประเภทการบริหารจัดการของพิพิธภัณฑ์ (9 ประเภท) | `หน่วยงานราชการ`, `วัด`, `ชุมชน` |
| `title` | String | ชื่อทางการของพิพิธภัณฑ์ | `พิพิธภัณฑ์กรมที่ดิน` |
| `creator` | String | ผู้จัดทำข้อมูล หรือผู้ก่อตั้งที่ระบุในบันทึก | `ชัยวัฒน์ ไชยประเสริฐ` |
| `provenance` | String | ประวัติความเป็นมาและการได้มาของคลังวัตถุ | `-` หรือข้อความประวัติ |
| `subjectRaw` | String | ข้อความหัวเรื่องต้นฉบับก่อนการทำความสะอาด | `พรมแดน, ตราประทับ, กรมที่ดิน` |
| `subjectList` | Array<String> | รายการหัวเรื่องที่ผ่านการแยกและทำความสะอาดแล้ว | `["พรมแดน", "ตราประทับ", "กรมที่ดิน"]` |
| `spatial` | String | ที่อยู่และสถานที่ตั้งเชิงบรรยาย | `ถ.พระพิพิธ แขวงพระบรมมหาราชวัง เขตพระนคร กรุงเทพฯ` |
| `province` | String | ชื่อจังหวัดที่สกัดได้จากที่อยู่ | `กรุงเทพมหานคร`, `เชียงใหม่` |
| `temporal` | String | ปี พ.ศ. ที่ก่อตั้งหรือยุคสมัยทางประวัติศาสตร์ | `2544` |
| `language` | String | ภาษาที่ใช้ในการจัดแสดงและสื่อความหมาย | `ไทย` |
| `rights` | String | ข้อมูลสิทธิ์และการเผยแพร่ | `-` |
| `license` | String | สัญญาอนุญาตตามชุดข้อมูลเปิด | `DGA Open Government License` |
| `sourceUri` | String | URL เชื่อมโยงกลับไปยังฐานข้อมูล ศมส. ต้นทาง | `https://db.sac.or.th/museum/museum-detail/1` |
| `imageUrl` | String | URL รูปภาพภายนอกที่ได้รับอนุญาต (HTTPS) | `https://example.com/photo.jpg` |
| `imageAlt` | String | คำอธิบายภาพเพื่อการเข้าถึง (Accessibility) | `อาคารพิพิธภัณฑ์` |
| `status` | String | สถานะระเบียน (`published` \| `draft` \| `archived`) | `published` |
| `createdAt` | ISO DateTime | วันที่นำเข้าหรือสร้างระเบียน | `2020-12-14T06:20:00.000Z` |
| `updatedAt` | ISO DateTime | วันที่แก้ไขข้อมูลล่าสุด | `2026-10-20T00:00:00.000Z` |

## ตารางหัวเรื่องภูมิปัญญา (Subject Entities)

| ชื่อฟิลด์ | ชนิดข้อมูล | คำอธิบาย | ตัวอย่างข้อมูล |
|---|---|---|---|
| `id` | String | รหัสหัวเรื่องแบบ Stable ID | `sub_5a8b9f12` |
| `name` | String | ชื่อหัวเรื่องภาษาไทย | `วิถีชีวิตท้องถิ่นและภูมิปัญญา` |
| `normalizedKey` | String | คีย์สำหรับตรวจจับคำพ้องเบื้องต้น | `วิถีชีวิตท้องถิ่นและภูมิปัญญา` |
| `count` | Number | จำนวนพิพิธภัณฑ์ที่จัดแสดงหัวเรื่องนี้ | `391` |
| `museumIds` | Array<String> | รายการรหัสพิพิธภัณฑ์ที่เชื่อมโยง | `["sac_1", "sac_4", ...]` |
| `status` | String | สถานะ (`active` \| `merged` \| `archived`) | `active` |
